# Roam hand-drawn app icon

Created with the built-in Image Gen tool on 2026-10-03, using the previous blue-and-white suitcase app icon as the reference. The user requested cute hand-drawn icons across iOS and macOS.

- `iOS-master.png`: opaque, full-bleed original artwork.
- `macOS-master.png`: the same artwork with a rounded blue tile and transparent exterior.
- Production app icons live in each platform's `Roam/Assets.xcassets/AppIcon.appiconset`. Sizes are exported with macOS `sips`; iOS remains opaque and macOS preserves alpha.

## iOS generation prompt

Edit the attached existing Roam travel app icon into a cute hand-drawn travel-journal illustration while preserving its recognizable suitcase subject and cheerful sky-blue brand background. This is a production app icon asset, not a mockup: exactly one square 1024 x 1024 opaque full-bleed image, no phone, no text, no lettering, no rounded-square mask, no external frame, no black border, no drop shadow around the canvas. The sky-blue paper-like background must extend to all four edges. Center a large soft ivory-white rolling suitcase occupying about 65% of the canvas, with a rounded hand-drawn handle and two small wheels; charming slightly imperfect navy pencil/ink outlines with smooth clear contours, very subtle colored-pencil texture, a simple little curved smile and tiny warm blush accents on the suitcase, plus one small blue travel-tag detail. Leave clean airy space around it. Light, warm, playful illustrated stationery aesthetic that complements a travel journal with handwritten notes and monochrome hand-drawn UI icons. Simple bold silhouette, very readable at 32 px; no photorealism, no glossy 3D, no clutter, no landscape, no miniature busy stamps. Preserve the blue-and-white suitcase identity in a delightful hand-drawn form.

## macOS generation prompt

Prepare the first reference as the macOS app icon version. Preserve the identical cute hand-drawn smiling ivory rolling suitcase, its heart travel tag, all illustration proportions, its navy pencil outlines, and the blue background from the first reference. Match only the second reference's macOS icon footprint and continuous rounded-square outer silhouette: a centered large blue rounded-square tile on a genuinely transparent outer margin of about 6% on all sides, without a black border or black backing. The full artwork of the first reference should fit the tile without clipping the handle or wheels. Do not redesign or add any element; no text, no desktop mockup, no shadow beyond tile, no white exterior rectangle. Production 1024x1024 PNG app icon with transparent corners and transparent exterior; the tile itself remains opaque sky blue. Keep the suitcase drawing exactly as in the first reference.

References for the macOS pass were the newly generated iOS artwork and the previous macOS icon silhouette. The tool produced 1254 x 1254 masters; final asset sizes were exported without changing the artwork.
