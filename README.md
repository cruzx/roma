# 漫游 · Roam

原生 SwiftUI 旅行规划 App，支持 iPhone 和 Mac（Mac Catalyst）。

## 功能

- 旅行首页、自适应卡片、长按拖动排序与搜索；iOS 首页置顶 4:3 今日行程卡，点击进入当天。
- iOS 首页提供 10 张 Pixabay 风景背景及相册自选图片，背景通过 CloudKit 保存与同步。图片来源链接在背景设置中保留。
- iOS 详情使用系统导航栏按钮与更多菜单，两端支持按天卡片浏览和天数拖动排序。
- 两端垃圾桶保留删除的旅行 30 天，支持恢复与彻底删除。
- 全程表格和按天查看，行程、交通、餐饮、住宿与备注。
- 地点搜索、多地点选择、地图路线与路线顺序调整。
- 自选封面：相册或图片文件，自动缩放压缩。
- 每条安排都可从相册或文件添加最多 8 张图片；五种安排分类均可使用，图片在表格和按天页面显示。
- 同一 iCloud 账户的私人数据库同步，离线保存及冲突副本。
- iOS 底部提供 Trips / Travel Journal 导航；手账支持左右滑动的画布，下拉展开相机，也可从相册选择照片，在设备上识别主体并制作透明贴纸，支持 4px 实线/虚线轮廓及描边颜色、长按拖动、缩放和旋转。双击画布空白处添加手写文字，文字可修改颜色、字号和位置。画布自动保存在本机，删除后可撤销；贴纸原图、文字、样式、位置、叠放顺序和画布位置自动同步至私人 iCloud。

## 项目

- `iOS/Roam.xcodeproj`：iPhone 工程。
- `macOS/Roam.xcodeproj`：Mac Catalyst 工程。
- 每个工程包含模型测试和 UI 测试。

使用 Xcode 27 打开工程，选择 `Roam` scheme 和对应运行设备。当前最低系统版本为 iOS 27.0、macOS 26.0。

## 内置旅行模板

两端首页在自己的旅行下方展示「推荐旅游模版」。包含北京 4 天、上海 3 天、广州 3 天、京都 4 天、神户 3 天、富士山 3 天、纽约 5 天、巴黎 4 天、伦敦 4 天、大连 3 天，共 36 天、248 条基础安排。

点击模板先预览，选择出发日期后创建独立旅行；每次创建会生成新的旅行、天数和安排 ID。模板原文不会被用户编辑影响，复制的旅行继续使用原有本地保存和 iCloud 同步。参考链接及整理日期会保留在第一天的备忘中。新安装从空白旅行库开始，已有用户的旅行不受影响；测试数据仍限于测试模式。

模板文字由漫游整理，参考资料为旅游局、政府和景点官方页面，整理日期为 2026-09-30。时间是规划建议，住宿仅给出区域；门票、预约、开放日和交通需要按实际出发日核对。富士山模板是山脚观景路线，不包含登顶。没有复制第三方攻略原文或新增未授权旅游照片，地图定位点需创建后自行添加。

内容在两端各自的 `Roam/TripTemplates.json`，两份需保持一致。模板读取和复制逻辑及页面在 `Roam/TripTemplates.swift`。模板模型测试覆盖内容完整性、复制 ID、选定日期、序列化及保存；iOS 流程测试覆盖首页模板预览与创建。

## 图标素材

iOS 与 Mac 共用圆润轮廓图标组件，覆盖导航、菜单、行程分类、交通方式、手账和拍照功能。界面采用 74 份可缩放模板矢量图，按确认的第三张预览统一为平滑粗线、圆头端点与简洁细节，其中 iOS 首页的设置、旅行、手账与搜索使用圆润实心款，其余继续跟随页面取色及深浅模式；见 [图标来源和许可](Design/IconSources/README.md)。应用图标为独立生成的手绘行李箱，iOS 使用不透明满版背景，Mac 保留透明圆角边缘；[原稿及生成说明](Design/AppIcon/README.md) 与最终尺寸资源均已纳入项目。

## iCloud 与签名

两端使用同一 CloudKit 私有容器 `iCloud.com.xiangchengjin.roam`。封面与安排图片随行程 payload 作为 CKAsset 同步，应用也保留本机副本。仓库不包含实际私人行程、上传照片、开发证书或描述文件。

Travel Journal 在现有 `RoamLibrary` 记录类型中使用独立的 `journal-board-v1` 清单和 `journal-image-<UUID>.png` 图片记录。编辑停止约 1 秒后自动同步，启动、返回前台以及运行期间每 30 秒检查更新；离线编辑保留到下次成功同步。先上传图片再发布画布清单，重复编辑复用已确认的图片；同时编辑同一对象时保留冲突副本。旧版本本机手账会自动迁移，设置中的 iCloud 页面显示手账同步状态。手账目前在 iOS 提供，Mac 行程同步维持原有功能。

手账横向浏览使用独立的逐帧位移和整层变换，复用贴纸描边、阴影与纸面网格。松手后短暂减速，再次拖动可接住当前画面；开启“减弱动态效果”时直接停在松手位置。画布停稳、切换页面或进入后台时保存位置，滑动帧内不写入文件或触发同步。

换开发团队时，请在 Signing & Capabilities 设置自己的团队和 Bundle ID，并为两个 App ID 关联同一容器；同步修改 `CloudSync.swift` 与 `Roam.entitlements` 的容器名。CloudKit 记录类型为 `RoamLibrary`，字段 `payload` 为 Asset。

当前安装测试使用 Development 环境；正式分发前需要部署生产 schema，并使用相应的分发签名。地图中的虚线是地点顺序示意，App 内道路计算支持步行和驾车；公共交通请在苹果地图查看。

## 验证

最近验证包括：两端构建通过，14 项模型测试通过；照片压缩、云端数据编码往返及无效图片测试通过；Mac 编辑、保存、重启持久化 UI 测试通过。Mac 私有云上传读取已实测。照片跨实体设备同步尚未独立验收。今日行程日期边界、背景持久化和东京车站实际搜索模型测试，以及今日卡比例/跳转/背景选择和中文东京车站加入路线 UI 测试通过；自选首页背景跨实体设备同步尚未独立验收。

UI 测试使用 `--uitesting` 的独立数据文件，不能对正常行程数据使用 `--reset`。

## AirDrop 分享旅行

打开旅行右上角菜单 → 分享旅行 / AirDrop → 在系统分享面板选择接收人。导出 `.roamtrip` 文件包含该旅行的完整安排、地图地点、备注、自选封面及各项安排图片，不包含其他旅行或账户信息。

接收方需安装支持本功能的漫游；打开文件会先显示导入预览，确认后新增独立旅行，并保存至接收方自己的 iCloud。也可从首页右上角加号 → 导入旅行文件。分享的是发送时的副本，后续修改不会自动同步给接收人。

验证：两端构建、分享文件往返与无效文件拒绝测试通过；Mac 文件打开与导入预览通过。真实跨设备 AirDrop 投递需接收设备配合，尚未独立验收。

### 从其他 App 收集备忘

在系统分享面板中选择「漫游」，可保存分享文字和网页链接，选择旅行及日期；下次打开漫游时归入当天备忘。不选日期的内容保留在首页设置 →「分享收集箱」，可稍后归档，也可手动粘贴其他 App 的分享文字。也可以直接从旅行详情展开当天安排，在备忘中点击「收藏攻略」粘贴链接，自动保存到当天备忘。iOS 每日卡片上滑展开当天安排后，可滚动查看多篇攻略；Mac 可在每日卡片内查看。粘贴分享文字或链接后打开归档页，会读取网页标题、公开正文或摘要，并在可用时附带作者和封面。点击卡片可打开原始链接；可重新读取。当天备忘中的链接也以卡片展示，编辑备忘可查看完整已读内容。网站需要登录、验证或没有公开正文时，会显示提示并保留原链接；不保证取得完整文章，不下载视频。已归档内容随旅行同步到 iCloud；尚未归档的收集箱保存在当前设备。

iOS 和 Mac Catalyst 均内嵌 RoamShare 扩展，通过 App Group `group.com.xiangchengjin.roam` 交换独立收集文件和旅行目录。分享扩展不直接修改行程；主 App 成功持久化后才移除收集文件，以稳定的 UUID 避免重复导入。
