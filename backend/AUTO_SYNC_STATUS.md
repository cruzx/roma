# 自动账号同步（2026-10-16）

- 会员登录、购买/恢复成功后自动建立独立资料空间并重建模型，无需启用按钮或重启；启动和每 30 秒检查可自动重试准备。
- 首次启用将原本机行程/手账复制到首个账号，保留原资料；后续其他账号不继承已有账号资料。已有账号空间不覆盖。退出后自动回原本机/iCloud 资料。
- 切换前停止并等待旧行程、手账、背景同步完成，防止旧任务使用新账号路径；多个窗口共享模型，过期模型不能触发切换。
- App 运行期间每 30 秒自动同步，返回前台同步；iOS 挂起时不保证执行频率。
- 删除启用、复制、重启、切回及手动同步按钮。账号管理、订阅管理折叠；照片继续依赖同一 Apple ID 的 iCloud。
- 11 项账号单元测试及 1 项账号页面 UI 测试通过，包含账号隔离导入规则及无手动同步按钮。iOS 真机构建和 Mac Catalyst 签名构建通过。
- Mac 已更新 /Applications/漫游-账号同步.app，启动验证原行程仍在，账号管理已折叠。手机当前 unavailable，安装待重新连接。
- 实际会员 Edge 服务未部署，当前请求返回 404；已替换为可读的未开放提示。未完成付费账号跨设备端到端验证，不应视为已上线；Apple 密钥及发布流程见 MEMBERSHIP_DEPLOYMENT.md。
